# Data Base Final Project 

## Overview
My project is an example of what I'm able to do with the knowlege aquired in my Data Fundamentals. It shows the normalization process of the information present on a sign up sheet of a volleyball team; The code used on SQL to create a crow's foot ERD to showcase the final structure; And finally the Acess part, where one can enter new information, visualize the relationships and generate reports on it.   

## Objective
It was created to organize information of a sign up sheet of a volleyball team.

## Key Insights
- The dataset does not contain user-submitted values, which prevents behavioral or trend analysis.
- While no conclusions can be drawn from the data itself, the structure of the sign-up sheet defines the type of insights that could be generated once populated.
- The absence of mandatory fields limits the reliability and completeness of future data collection.
- Additional fields such as timestamps, user categories, or consent indicators would enable meaningful segmentation and analysis.
- This project highlights the importance of data collection design as a critical first step in the analytics lifecycle.
